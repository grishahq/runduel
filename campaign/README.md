# RunDuel launch kit

Five distinct English story beats for Agno application developers, with five
LinkedIn posts and five corresponding four-post X threads. All LinkedIn posts
are below 3,000 characters; all X posts are below 280 characters even when full
URLs are counted. Audience, hook, evidence, call to action, alt text and image
are specified for every beat.

- `CAMPAIGN.md`: copy for review and reuse.
- `campaign.json`: structured copy, character counts and metadata.
- `assets/`: two original generated concept illustrations, one genuine product
  screenshot, a plotted execution-results chart and a release quickstart card.
- `provenance.json`: prompts, generation source provenance and capture/plot sources.
- `schedule.json`: exact prepared/scheduled/published states and access blocker.
- `runduel-launch-kit.zip`: portable copy of these campaign files and all assets.

The GitHub v0.1.0 release is public, immutable and independently downloaded and
installed. Public release claims in the copy point to that verified release.

failed with `Debugger unattached` after an X navigation timeout; no social plugin
is connected. LinkedIn owner profile was verified before detachment; X account
ownership was not newly read back. Existing unrelated posts were not changed.
